# Agent Headers Observatory

**The public dataset of websites that talk to AI agents through HTTP headers** — urlscan.io for the agent-header era.

## Why this exists

In October 2026, researchers found ~8,000 websites using HTTP response headers to communicate with AI agents — and 30 attempting indirect prompt injection through those headers. Nobody publishes the ongoing picture. This project does: a versioned, community-built dataset of real header observations, so researchers, builders, and security teams can see which sites speak to agents and which ones try to manipulate them.

## v0.1 scope (honest)

- **44 sites** scanned on 2026-10-16 with [header-hunter](https://github.com/Iceman2050/header-hunter) (tech news, docs sites, AI companies, SaaS homepages).
- **Result: 43 informational, 1 agent-directed** (replicate.com serves an agent-discovery `Link` header), **0 suspicious**.
- Every row is a real tool output. Failed scans are kept with their error, not dropped. Aggregate stats are generated by `tools/stats.py`, never hand-typed.

This is a seed, not a census. v0.1 proves the pipeline; the value compounds as contributors add observations.

## Contents

- `dataset/observations-2026-10-16.json` — the v0.1 dataset (schema v0.1, see `SCHEMA.md`)
- `tools/stats.py` — regenerates aggregate stats from the dataset
- `site/index.html` — static overview page with stats, methodology, and download link
- `CONTRIBUTING.md` — how to add your scans

## Roadmap

- Continuous scanning (weekly re-scans of the seed list, trend lines per site)
- HTTP API for the dataset
- Suspicious-header alert feed
- Pairing with [attack-matrix-mapper](https://github.com/Iceman2050/attack-matrix-mapper) for ATT&CK v20 mapping of confirmed cases
