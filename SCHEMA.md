# Observation schema — v0.1

Dataset files live in `dataset/` as `observations-YYYY-MM-DD.json`.

## Top-level

| Field | Type | Description |
|---|---|---|
| `schema_version` | string | `"0.1"` |
| `generated_at` | string | ISO-8601 UTC timestamp of dataset build |
| `scanner` | string | Scanner name/version that produced the observations |
| `observations` | array | One object per scanned URL |

## Observation

| Field | Type | Description |
|---|---|---|
| `url` | string | URL as requested |
| `final_url` | string | URL after redirects |
| `observed_at` | string | ISO-8601 UTC timestamp of this scan |
| `status` | integer | Final HTTP status (0 if the request failed) |
| `headers_of_interest` | array | Findings with category `agent-directed` or `suspicious` only |
| `verdict` | string | Scanner verdict: `agent-directed`, `suspicious`, `informational`, or `clean (no agent-relevant headers detected)` |
| `error` | string | Empty on success; fetch error message otherwise |

## Finding (inside `headers_of_interest`)

| Field | Type | Description |
|---|---|---|
| `header` | string | Header name (lowercased) |
| `value` | string | Raw header value |
| `category` | string | `agent-directed` or `suspicious` |
| `detail` | string | Why the scanner flagged it |

## Honesty rules (enforced, not aspirational)

1. Every observation must come from a real scanner run. Fabricated rows are rejected.
2. `suspicious` means *possible* indirect prompt injection — unconfirmed by definition. Never relabel as confirmed.
3. Failed scans stay in the dataset with `error` set; they are not silently dropped.
4. Aggregate numbers on the site are generated by `tools/stats.py` from the dataset — never hand-typed.
